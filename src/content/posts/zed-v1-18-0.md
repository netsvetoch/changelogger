Zed выпустил minor-релиз [`v1.18.0`](https://github.com/zed-industries/zed/releases/tag/v1.18.0). Это не pointer-only release: основной источник — GitHub Release и связанные PR. Главные пользовательские изменения — inline-значения переменных при отладке C и C++ через CodeLLDB/GDB, переработанная типографика Markdown preview, история File Finder, которая переживает перезапуск, настройка debounce для inline-подстановок и новые модели в панели агента.

Для разбора проверены release notes и реализации PR [`#46705`](https://github.com/zed-industries/zed/pull/46705) (инлайн C/C++), [`#63118`](https://github.com/zed-industries/zed/pull/63118) (markdown preview), [`#55034`](https://github.com/zed-industries/zed/pull/55034) (история File Finder), [`#61568`](https://github.com/zed-industries/zed/pull/61568) (prediction_debounce), [`#62966`](https://github.com/zed-industries/zed/pull/62966) (toggle diff base), [`#63135`](https://github.com/zed-industries/zed/pull/63135) (Continue Program/Thread) и [`#58729`](https://github.com/zed-industries/zed/pull/58729) (ключевые привязки дебаггера).

## Inline-значения дебаггера для C и C++ (CodeLLDB/GDB)

PR [`#46705`](https://github.com/zed-industries/zed/pull/46705) добавляет файл декомпозиции отладчика (`debugger.scm`) для языков C и C++. Теперь при отладке с адаптерами CodeLLDB или GDB значения локальных переменных показываются inline прямо в gutter у строки приостановки — так же, как ранее было доступно для других языков. До релиза для C/C++ inline-значения не генерировались, и значения приходилось смотреть в Debug Panel.

Работает это через tree-sitter-скрипт, который сопоставляет синтаксические узлы выражений с их значениями из адаптера. Проверить проще всего так: поставьте точку останова, запустите отладку через CodeLLDB или GDB и приостановите исполнение — inline-значения появятся в gutter у соответствующих строк.

## Переработанная типографика Markdown preview

PR [`#63118`](https://github.com/zed-industries/zed/pull/63118) меняет дефолтные стили Markdown preview, приближая его к рендерингу GitHub. Все изменения без новых настроек — принцип «хороший дефолт лучше лишних ручек» из обсуждения к PR (см. комментарии в `#60402`/`#59544`).

Что конкретно поменялось:

- body-текст рендерится в полный размер `markdown_preview_font_size` и полным контрастом 1:1 (раньше — 92% этого значения в приглушённом цвете);
- line height body, списков и blockquote теперь 1.5 (раньше абзацы переопределяли базовый line height значением `rems(1.3)`);
- абзацы, списки, blockquote, разделители и code-блоки разнесены на 16px;
- заголовки semibold: от h1 `1.75rem` до h6 `0.85rem`; нижняя граница осталась только у h1 и h2, borderline у h3 убран;
- inline code получил скруглённый фон-«чип» вместо квадратной подложки: чипы трекаются по rendered-индексам, покрывают ровно глифы кода и выступают за них на 1px, так что пробелы между словами остаются полной ширины;
- code-блоки — отступ 12px, скругление углов 6px; у ссылок убран фоновый tint; текст blockquote приглушён; ячейки таблиц получили паддинги 10px (горизонталь) и 4px (вертикаль).

В коде crate `markdown` добавлен тест, проверяющий, что inline-чипы покрывают ровно глифы span и что чипы не создаются при нулевом радиусе скругления. Откройте любой `.md` файл и выполните `markdown: open preview` — agent panel и hover-tooltip используют тот же рендерер, но сохраняют старые параметры.

## История File Finder между сессиями

PR [`#55034`](https://github.com/zed-industries/zed/pull/55034) сохраняет недавнюю историю навигации (до 20 записей) в workspace-базу и делает так, чтобы она переживала перезапуск. При повторном открытии workspace сохранённые пути, которые резолвятся в текущий проект, вливаются в историю File Finder с дедупликацией против файлов, уже открытых в текущей сессии. То есть после `cmd-p` снова видны файлы, открывавшиеся в прошлый раз, но без дубликатов. Закрывает issue [`#56271`](https://github.com/zed-industries/zed/issues/56271).

## `edit_predictions.<provider>.prediction_debounce`: настраиваемый debounce inline-подстановок

PR [`#61568`](https://github.com/zed-industries/zed/pull/61568) делает задержку перед рендером inline-подстановок настраиваемой для любого провайдера (ранее для Codestral был захардкожен `DEBOUNCE_TIMEOUT` 150ms, для Copilot — 75ms). Теперь можно указать свой интервал:

```json
{
  "edit_predictions": {
    "openai": {
      "prediction_debounce": 200
    }
  }
}
```

Допустимы значения в миллисекундах — и в виде чистого числа, и со строковым суффиксом `"ms"` (например `"300ms"`): в PR заодно исправлен парсинг `DelayMs`, который раньше добавлял `"ms"` в поле ввода и не мог распарсить `"150ms"` как `u64`. Строковый `FromStr` теперь отбрасывает суффикс `ms`, если он присутствует. Поведение подтверждено тестом `test_refresh_prediction_from_buffer_honors_debounce_duration`. Настройка применима live, без перезапуска.

## Дебаггер: разделение Continue Program и Continue Thread (+ breaking-перепривязка ключей)

PR [`#63135`](https://github.com/zed-industries/zed/pull/63135) чинит отладку в многопоточных процессах. Раньше Continue Program отправлял адаптеру `singleThread: true` всякий раз, когда тот его поддерживал, из-за чего некоторые адаптеры возобновляли только выбранный поток. Теперь Continue Program оставляет `singleThread` неустановленным и возобновляет все потоки. Для адаптеров, поддерживающих выполнение одного потока, появились отдельные кнопки **Continue Program** и **Continue Thread**; остальные по-прежнему показывают только Continue Program.

Сопутствующие исправления: состояние потоков обновляется из ответа на continue, а не из отложенного события `continued` (адаптеры не обязаны его слать), и пропущенный `allThreadsContinued` в событии `continued` теперь трактуется как `true`, согласно DAP-спецификации.

Отдельный breaking-change из PR [`#58729`](https://github.com/zed-industries/zed/pull/58729): привязки шагов отладчика приведены к дефолтам VS Code. Теперь на всех платформах, пока исполнение приостановлено, `f10` = Step Over, `f11` = Step Into; старый `ctrl-f11` (Step Into) сохранён, на Linux/macOS остались и прежние `f7` (Step Over)/`shift-f11` (Step Out). Раньше на Windows не было вовсе биндинга Step Into, а `f11` был занят `zed::ToggleFullScreen`, поэтому переключатель полный экран вынесен в контекст `Workspace`, чтобы его можно было переопределить. Во вне-paused-сессии `f11` по-прежнему работает как полноэкранный режим.

## AI: новые модели и начало перехода на Gemini 3.5 Flash-Lite

В панель агента добавлены модели из нескольких провайдеров:

- GPT-5.6 с окном контекста в 1M токенов на Amazon Bedrock ([`#63069`](https://github.com/zed-industries/zed/pull/63069));
- Grok 4.5 и 4.6 в xAI-моделях ([`#63234`](https://github.com/zed-industries/zed/pull/63234));
- Gemini 3.5 Flash-Lite в Google AI ([`#63129`](https://github.com/zed-industries/zed/pull/63129)).

Breaking-change по Google AI ([`#63131`](https://github.com/zed-industries/zed/pull/63131)): из списка удалены Gemini 2.5 Flash-Lite, Gemini 2.5 Flash, Gemini 2.5 Pro и Gemini 3.1 Flash-Lite; теперь Gemini 3.5 Flash-Lite назначен моделью по умолчанию и «быстрой» моделью. Если у вас в настройках/`agent` была явно указана одна из удалённых моделей, замените её на актуальную.

Также в AI-части: настройка автокомплита в fields для OpenAI subscription provider ([`#62989`](https://github.com/zed-industries/zed/pull/62989)), перезагрузка сломанного внешнего agent-соединения прямо из Agent Panel без перезапуска ([`#62669`](https://github.com/zed-industries/zed/pull/62669)), улучшена поддержка Claude Fable 5.1 ([`#63571`](https://github.com/zed-industries/zed/pull/63571)), в ошибках подключения к LM теперь указывается недостижимый хост ([`#62990`](https://github.com/zed-industries/zed/pull/62990)) и снижено потребление памяти в длинных agent-сессиях ([`#63053`](https://github.com/zed-industries/zed/pull/63053)).

## Git: toggle diff base и другие мелочи

PR [`#62966`](https://github.com/zed-industries/zed/pull/62966) добавляет экшен `git: toggle diff base`, который переключает настройку `git.diff_base` между `head` и `default_branch` (та же настройка, что стала доступна в `v1.15.0`). Это быстрый способ переключить gutter/цвета файлов с отображения только незакоммиченных правок на полный diff ветки против default branch.

Дополнительно: permalink-поддержка для репозиториев Tangled ([`#63051`](https://github.com/zed-industries/zed/pull/63051)), Git Graph/history теперь по умолчанию фокусируются на поле поиска ([`#63002`](https://github.com/zed-industries/zed/pull/63002)), а «Discard Tracked Changes» в Git Panel ограничивается файлами из той директории, где открыто контекстное меню ([`#62872`](https://github.com/zed-industries/zed/pull/62872)).

## Прочее: Languages, Terminal, Linux и breaking-заметки

- **Bash Language Server**: добавлена настройка через `lsp.bash-language-server.settings` ([`#57487`](https://github.com/zed-industries/zed/pull/57487)) — конфигурируйте bash-language-server прямо из файла настроек Zed.

```json
{
  "lsp": {
    "bash-language-server": {
      "settings": {
        "bashIde": {
          "shfmt": {
            "binaryNextLine": true,
            "caseIndent": true,
            "spaceRedirects": true,
            "simplifyCode": true
          }
        }
      }
    }
  }
}
```

Общий принцип: любые опции `bashIde.*` из [конфигурации bash-language-server](https://github.com/bash-lsp/bash-language-server/blob/main/server/src/config.ts) можно задать здесь; пример выше — настройки shfmt из тестов PR.

- **Terminal**: поддержка комбинаций `ctrl-alt-<letter>` и `alt-f5` ([`#62891`](https://github.com/zed-industries/zed/pull/62891)).
- **Markdown/Git**: исправлен soft-wrap для закрывающих знаков препинания и слэшей ([`#62743`](https://github.com/zed-industries/zed/pull/62743)); в Mermaid-диаграммах корректно переносятся подписи ([`#62931`](https://github.com/zed-industries/zed/pull/62931)).
- **Linux**: улучшена производительность рендеринга через прогрев кэша сопоставления шрифтов ([`#63158`](https://github.com/zed-industries/zed/pull/63158)) и кэширование глифов после измерения bounds ([`#63209`](https://github.com/zed-industries/zed/pull/63209)); исправлены пустые окна при первом открытии на X11 ([`#62081`](https://github.com/zed-industries/zed/pull/62081)), зависание UI в fullscreen на некоторых Wayland-композиторах ([`#60690`](https://github.com/zed-industries/zed/pull/60690)) и вечная метка внимания в taskbar/dock из-за некогда неочищенного X11 urgency hint ([`#61619`](https://github.com/zed-industries/zed/pull/61619)).
- **Breaking**: из Linux-архивов релиза удалены библиотеки GLib во избежание конфликтов с системными плагинами ([`#61593`](https://github.com/zed-industries/zed/pull/61593)).

Полный список фиксом и изменений — в [release notes](https://github.com/zed-industries/zed/releases/tag/v1.18.0).
